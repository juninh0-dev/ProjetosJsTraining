# 📝 To-Do List

Projeto simples de lista de tarefas desenvolvido com JavaScript.

## 🚀 Funcionalidades
- Adicionar tarefas
- Marcar tarefas como concluídas
- Remover tarefas
- Salvamento no LocalStorage

## 🛠️ Tecnologias
- HTML5
- CSS3
- JavaScript

## 🎯 Objetivo
Praticar manipulação do DOM, eventos e armazenamento local com LocalStorage.

## 📂 Como executar
1. Clone o repositório
2. Abra o arquivo `index.html` no navegador
