# 🌤️ Aplicação de Clima

Projeto desenvolvido em HTML, CSS e JavaScript para consulta de informações climáticas em tempo real utilizando a API da OpenWeather.

## Funcionalidades

* Busca de clima por nome da cidade.
* Consumo de API utilizando `fetch()` e `async/await`.
* Exibição de:

  * Nome da cidade
  * Temperatura atual em Celsius
  * Descrição das condições climáticas
* Tratamento de erros para cidades inválidas.
* Validação de campo vazio antes da consulta.

## Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript (ES6+)
* OpenWeather API

## Conceitos Praticados

Durante o desenvolvimento deste projeto foram aplicados conceitos importantes de JavaScript, como:

* Manipulação do DOM
* Eventos de clique
* Template Strings
* Funções Assíncronas (`async/await`)
* Consumo de APIs REST
* Tratamento de erros com `try/catch`
* Manipulação de Objetos e Arrays JSON

## Como Utilizar

1. Digite o nome de uma cidade.
2. Clique em **Obter Clima**.
3. Aguarde a consulta à API.
4. As informações climáticas serão exibidas na tela.

## Objetivo

Este projeto foi desenvolvido com o objetivo de praticar o consumo de APIs em JavaScript, compreender o funcionamento do método `fetch()` e trabalhar com dados retornados em formato JSON.
